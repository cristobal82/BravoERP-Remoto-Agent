# Security policy

## Supported releases

Only the latest published BravoERP Remoto Agent release is intended to receive security fixes.
Until this fork publishes its first release, no production release is declared supported.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is enabled for this repository. If private
reporting is unavailable, contact the repository owner without including exploit details or
sensitive customer information in a public issue.

Never publish credentials, private keys, server configuration, customer data, device identifiers,
or access tokens.

## Scope and safe testing

Security testing must be performed only on systems and accounts the researcher owns or is expressly
authorized to test. Do not disrupt third-party services, access customer devices, retain personal
information, or attempt to bypass consent and authorization controls.
