# Privacy policy

Last updated: 2026-10-07

## Purpose

BravoERP Remoto Agent is software for authorized remote support and device administration. It is
derived from the Apache-2.0 licensed MeshAgent project.

## Network communication

The agent connects only to the MeshCentral server selected and configured by the person or
organization installing it. The agent does not independently choose an advertising, analytics, or
data-broker service.

Depending on server policy and actions performed by authorized support personnel, the agent may
transmit device identity and status, operating-system and network information, event and diagnostic
data, terminal traffic, remote-desktop screen/input data, and files explicitly transferred through
the remote-support session.

## Control and consent

The organization operating the configured MeshCentral server is responsible for informing users,
obtaining any required authorization, configuring consent prompts and access controls, limiting
retention, and protecting server-side data. Remote sessions must be used only on systems for which
the operator has authorization.

## Third parties

This project contains no advertising SDK and does not sell personal information. Network traffic is
sent to the configured MeshCentral deployment and to infrastructure explicitly selected by its
operator. Dependencies and platform services may have their own policies.

## Removal

The Windows service can be removed using MeshAgent's supported uninstall command or the removal
workflow provided by the corresponding MeshCentral server administrator.

## Public repository

Do not submit logs, screenshots, configuration files, device identifiers, customer information,
credentials, or private keys to public issues. Use a private security-reporting channel for
sensitive reports.
